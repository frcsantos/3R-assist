## Conceito

**Assist3R** é uma ferramenta de apoio à decisão baseada em IA para pesquisadores e Comissões de Ética no Uso de Animais (CEUAs) descobrirem alternativas validadas ao uso de animais.

O usuário descreve um protocolo experimental em texto livre (português ou inglês). O sistema extrai os parâmetros centrais, compara-os com uma base de dados curada de métodos e devolve recomendações classificadas de acordo com os **3Rs** (Substituição / Redução / Refinamento), com validade jurisdicional e links para as fontes primárias.

## Como usar

1. **Analisar** — Cole um protocolo em texto livre (ou envie PDF/HTML/TXT); envie.
2. **Parâmetros** — Revise os campos extraídos, os selos de confiança e os destaques de evidência; edite se necessário; confirme.
3. **Resultados** — Navegue pelas alternativas classificadas (3Rs, % de correspondência, linhas de detalhes, jurisdições, fontes). Filtre por 3Rs / jurisdição quando necessário.
4. **Literatura** — Para cada experimento, abra a análise de literatura baseada no PubMed: hipótese do desfecho, veredito sobre a necessidade do uso de animais, literatura de apoio classificada com citações.
5. **Explorar** — Navegue por Métodos / Regulamentos / Documentos. Use o **!** em um cartão para enviar feedback sobre aquele item.
6. **Glossário / Info** — Termos do domínio e contexto do projeto.
